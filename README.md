# Supply Chain Analytics

This repository showcases projects that apply data analytics, optimisation and business intelligence to improve supply chain, logistics and warehouse operations.

---

## Repository Overview

The projects in this repository demonstrate how data-driven decision-making can improve inventory management, warehouse performance, transportation planning and overall supply chain efficiency.

The portfolio combines Industrial Engineering principles with modern analytics and machine learning techniques to solve real-world operational challenges.

---

## Areas Covered

- Inventory Management
- Warehouse Analytics
- Logistics Performance
- Demand Forecasting
- Inventory Optimisation
- ABC Classification
- Economic Order Quantity (EOQ)
- Safety Stock Analysis
- Capacity Planning
- Transportation Analytics
- Supply Chain KPIs
- Order Fulfilment (OTIF)
