# Datasets

This directory contains datasets used throughout the Supply Chain Analytics portfolio.

Datasets are sourced from publicly available repositories or created using simulated data where confidential business information cannot be shared.

## Dataset Categories

- Inventory Data
- Warehouse Operations
- Customer Orders
- Transportation
- Demand History
- Production Planning
- Supplier Performance
- Logistics KPIs

Each dataset is accompanied by documentation describing its structure, variables and intended analytical purpose.
