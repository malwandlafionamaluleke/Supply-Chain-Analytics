# Jupyter Notebooks

This directory contains Python notebooks developed for Supply Chain Analytics projects.

The notebooks demonstrate analytical workflows, data processing techniques and predictive modelling approaches commonly applied within logistics and supply chain management.

Topics include:

- Data Cleaning
- Exploratory Data Analysis
- Inventory Analytics
- Demand Forecasting
- Machine Learning
- Statistical Analysis
- Optimisation
- Data Visualisation

Each notebook is designed to provide a reproducible and well-documented analytical workflow.
