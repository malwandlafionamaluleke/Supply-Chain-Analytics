# Projects

This directory contains end-to-end Supply Chain Analytics projects that address real-world logistics, warehousing and inventory management challenges.

Each project is structured to demonstrate the complete analytics lifecycle, including problem definition, data preparation, analysis, modelling, visualisation and business recommendations.

## Project Categories

- Inventory Management
- Demand Forecasting
- Warehouse Analytics
- Logistics Performance
- Inventory Optimisation
- Transportation Analytics
- Capacity Planning
- Supply Chain KPI Reporting
- Order Fulfilment (OTIF)
- Network Optimisation

Each project includes documentation, code, visualisations and key business insights.
